
#  Proyecto de GM RP by alaska
Eso es un proyecto tonto que estoy haciendo como hobby para practicar programación y diseño de software. La gamemode está enfocada en el ámbito roleplay, siendo ésta modular (o eso intento).

## Includes
- a_mysql
- Pawn.CMD
- sscanf2
- streamer
- YSI-Include
- easyDialog
- samp_bcrypt
  

## Plugins
- crashdetect — Para detectar crashes fácil.
- mysql — Para base de datos.
- samp_bcrypt - Para encriptar información.
- sscanf - Para manejo de strings.
- streamer - Para modificar límites de SA-MP
